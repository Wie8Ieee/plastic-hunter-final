# Marine Dataset Demo Images

These images are selected from dataset sources, not random web image search.

Current source: TACO - Trash Annotations in Context: https://github.com/pedropro/TACO

Important: TACO is mixed-environment. The files here were visually selected from the imported TACO subset because they show sand/coastal context. For the strongest project alignment, replace or augment them with BePLi beach plastic litter, Trash-ICRA19 marine debris, River Floating Trash, or Roboflow Beach Waste exports.

No fake labels were created. Missing clean beach and marine fishing-net samples are documented in manifest.json.
