# Dataset Demo Images

These demo samples are copied from real dataset sources, not random web images.

Source used for current positive samples: TACO - Trash Annotations in Context
https://github.com/pedropro/TACO

Files 01-04 include their original YOLO label files converted from TACO COCO annotations.

The requested clean beach negative sample is intentionally not filled with a random image. Add it only from a verified dataset/background split such as BePLi or Roboflow if a true no-plastic beach image is available. See manifest.json for details.
